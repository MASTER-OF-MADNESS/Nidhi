# Top 70 NGO Backup Dataset for Temenos CSR Matching

> **Important:** “Top” here means a **curated shortlist for the PS2 application**, not an official government ranking or Temenos-approved ranking. The shortlist emphasizes CSR relevance, geographic presence, program breadth, public transparency/compliance signals, and usefulness for the application's matching model. The live application should still verify current information before making a recommendation.

## Dataset structure

Each NGO record is designed as a backup profile. Runtime web search should enrich and verify: budget capacity, current projects, current compliance, exact districts served, current beneficiaries, recent outcomes, ratings, collaboration capacity, and current Temenos relationship where applicable.

## Critical distinction

These 70 NGOs are **potential CSR implementation candidates**, not necessarily Temenos partners. Do **not** claim that any organization is affiliated with Temenos unless a separate Temenos source explicitly proves that relationship. The existing Temenos partner knowledge base remains the source for verified Temenos relationships.

# Runtime Matching Rules

1. Treat this dataset as a **candidate discovery layer**, not final truth.
2. Perform live web search for every serious recommendation.
3. Verify the NGO's current legal/compliance status before funding.
4. Verify current geographic coverage at district level.
5. Verify current project experience and recent outcomes.
6. Verify funding/project capacity against the CSR budget.
7. Do not score missing information as a positive.
8. Do not call an NGO a Temenos partner without explicit evidence.
9. Separate NGO eligibility from NGO suitability.
10. Apply the CSR manager's runtime requirements before ranking.
11. Record evidence source and verification date for each runtime fact.
12. Keep the final recommendation explainable and auditable.
