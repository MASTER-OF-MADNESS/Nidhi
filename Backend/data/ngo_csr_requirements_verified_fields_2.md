# Why Many Fields Are Blank

The requested fields are intentionally not guessed. An NGO normally does not have one universal CSR budget, project duration, minimum funding or maximum funding applicable to every project. Those values depend on the specific proposal and funding round.

Current district coverage, current ratings, current compliance status, similar-project evidence and collaboration capability should be refreshed through live web research or NGO documents.
