# Temenos NGO Master Knowledge Base

## Purpose

This is a **backup/reference knowledge base** for a dynamic AI-powered CSR Fund Allocation & Project Prioritization application for Temenos.

The live application should perform **live web search and current verification** at runtime. This file provides baseline Temenos CSR/community context and a verified public candidate pool of organizations with documented Temenos relationships.

> **Important:** This is not a permanent NGO ranking. The application must dynamically evaluate candidates against the CSR manager's runtime requirements.

---

# 1. Evidence and Classification Rules

## Evidence types

| Evidence Type | Meaning |
|---|---|
| `VERIFIED_OFFICIAL` | Directly supported by an official Temenos source. |
| `VERIFIED_ORGANIZATION` | Supported by the organization's own source. |
| `VERIFIED_SECONDARY` | Supported by a reputable secondary source. |
| `INFERENCE` | Reasonable conclusion not explicitly stated by Temenos. |
| `PROPOSED` | Hackathon/application recommendation, not Temenos policy. |
| `NOT_PUBLICLY_DISCLOSED` | Reliable public evidence was not found. |

## Relationship types

| Relationship Type | Meaning |
|---|---|
| `DIRECT_CSR_PARTNER` | Direct Temenos CSR/community-investment relationship. |
| `COMMUNITY_PARTNER` | Partner in a Temenos community initiative/event. |
| `GOVERNMENT_PARTNER` | Government/municipal body involved in a Temenos project. |
| `EMPLOYEE_VOLUNTEERING_PARTNER` | Organization involved mainly through employee volunteering. |
| `FINANCIAL_INCLUSION_ENABLEMENT` | Financial institution/customer relationship; not automatically CSR. |
| `OTHER_VERIFIED_RELATIONSHIP` | Other verified relationship. |

**Critical rule:** A Temenos customer must not automatically be treated as a CSR NGO.

# 11. Proposed NGO Matching Model

> **PROPOSED FOR OUR HACKATHON — NOT AN OFFICIAL TEMENOS MODEL**

## Hard eligibility filters

Before scoring:

1. Required legal/compliance requirements satisfied.
2. Required geography covered.
3. Required sector supported.
4. Required beneficiary group supported.
5. Required collaboration model feasible.
6. Required documents available where mandatory.
7. No disqualifying risk.

If a mandatory requirement fails:

```text
ELIGIBILITY = INELIGIBLE
```

A high soft score must not override a hard eligibility failure.

## Proposed 100-point score

| Parameter | Weight |
|---|---:|
| CSR sector alignment | 15 |
| Geographic match | 12 |
| Beneficiary match | 10 |
| Similar project experience | 12 |
| NGO operational capability | 10 |
| Compliance | 10 |
| Past performance | 8 |
| Temenos strategic fit | 8 |
| Collaboration fit | 5 |
| Impact measurement capability | 4 |
| Sustainability/scalability | 3 |
| Risk profile | 3 |
| **Total** | **100** |

## Score interpretation

| Score | Interpretation |
|---|---|
| 90–100 | Exceptional match |
| 80–89 | Strong match |
| 70–79 | Good match |
| 60–69 | Moderate match |
| <60 | Weak match |

# 19. Important Data Limitations

- Temenos does not publicly disclose a universal real-time NGO ranking.
- Temenos does not publicly disclose a universal NGO scoring formula.
- Temenos does not publicly disclose a single geographic allocation formula for all CSR/community investment.
- Historical project information can be more detailed than current partner funding information.
- Some NGO financial/compliance fields may require direct NGO documentation or government verification.
- Employee-volunteering relationships should not automatically be interpreted as direct funding relationships.
- Financial-inclusion customer relationships should not automatically be interpreted as CSR relationships.
- Historical funding amounts should not be interpreted as current annual CSR budget unless explicitly stated.
